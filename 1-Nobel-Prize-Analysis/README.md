# Nobel Prize Analysis

## Overview
This project analyzes the Nobel Prize dataset to uncover insights about prize winners, categories, and trends over time.

## Dataset
- **File**: `data/nobel.csv`
- **Content**: Nobel Prize winners data including names, fields, years, and categories

## Project Goals
- Analyze distribution of Nobel Prizes across different fields
- Identify trends in winners over decades
- Explore geographical patterns of Nobel laureates
- Generate visualizations of key insights

## Files
- `notebook.ipynb` - Main analysis notebook
- `data/nobel.csv` - Nobel Prize dataset
- `Nobel_Prize.png` - Project visualization/reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn

## Data Science Concepts Covered
- **Exploratory Data Analysis (EDA)** - Data exploration and summary statistics
- **Data Visualization** - Creating insightful charts and graphs
- **Aggregation & Grouping** - Summarizing data by categories
- **Temporal Analysis** - Analyzing trends over time
- **Statistical Analysis** - Descriptive statistics and distributions
- **Pattern Recognition** - Identifying trends and patterns

## Key Insights
- Explore patterns in Nobel Prize distribution
- Analyze gender distribution across categories
- Study temporal trends in prize-winning
