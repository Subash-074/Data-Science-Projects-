# HR Customer Analysis

## Overview
This project analyzes human resources and customer training data to identify patterns in employee performance, training effectiveness, and customer outcomes.

## Dataset
- **File**: `customer_train.csv`
- **Content**: HR training data with employee information and outcomes

## Project Goals
- Analyze training effectiveness
- Identify patterns in employee performance
- Evaluate customer satisfaction metrics
- Determine factors contributing to successful outcomes
- Explore demographic patterns

## Files
- `notebook.ipynb` - Main analysis notebook
- `customer_train.csv` - HR and customer data
- `hr-image-small.png` - HR reference image
- `.jupyter/lab/workspaces/` - Jupyter Lab configuration

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Data Science Concepts Covered
- **Classification Analysis** - Categorizing outcomes
- **Predictive Modeling** - Forecasting performance and retention
- **Correlation Analysis** - Identifying key relationships
- **Exploratory Data Analysis** - Understanding patterns
- **Demographic Analysis** - Segment and cohort analysis
- **Performance Metrics** - Evaluating success factors
- **Statistical Testing** - Hypothesis validation

## Key Insights
- Training impact on employee performance
- Demographic patterns in success rates
- Customer satisfaction correlations
- Predictive factors for employee retention
