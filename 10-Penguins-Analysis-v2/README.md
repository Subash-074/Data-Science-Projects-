# Penguins Analysis - Version 2

## Overview
This project provides an in-depth analysis of the Palmer Penguins dataset with advanced techniques, deeper insights, and enhanced modeling.

## Dataset
- **File**: `penguins.csv`
- **Content**: Palmer Penguins data with species, island, measurements (culmen, flipper, body mass), and sex

## Project Goals
- Advanced species classification models
- Deep exploration of measurement relationships
- Statistical hypothesis testing
- Feature engineering and selection
- Model optimization and comparison

## Files
- `notebook.ipynb` - Advanced analysis notebook
- `penguins.csv` - Palmer Penguins dataset

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Advanced machine learning techniques

## Key Insights
- Enhanced classification accuracy
- Deeper feature relationships and interactions
- Statistical significance of differences
- Optimal modeling approaches
- Comparative analysis with version 1
