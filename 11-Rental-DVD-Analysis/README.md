# Rental DVD Analysis

## Overview
This project analyzes DVD rental data to understand rental patterns, customer preferences, and business insights.

## Dataset
- **File**: `rental_info.csv`
- **Content**: DVD rental transaction data with rental details, dates, and information

## Project Goals
- Analyze DVD rental trends and patterns
- Identify popular genres and titles
- Study rental frequency by customer segments
- Explore seasonal patterns in rentals
- Develop insights for rental business optimization

## Files
- `notebook.ipynb` - Main analysis notebook
- `rental_info.csv` - DVD rental dataset
- `dvd_image.jpg` - DVD reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Business analytics

## Data Science Concepts Covered
- **Time Series Analysis** - Temporal trend identification
- **Customer Segmentation** - Identifying customer groups
- **Business Analytics** - Revenue and performance metrics
- **Trend Analysis** - Seasonal and cyclical patterns
- **Exploratory Data Analysis** - Transaction profiling
- **Aggregation & Grouping** - Summary statistics
- **Categorical Analysis** - Genre and title preferences
- **Data Visualization** - Business metrics visualization

## Key Insights
- Popular genres and titles
- Customer rental patterns
- Seasonal trends in DVD rentals
- Revenue optimization opportunities
- Customer segmentation insights
