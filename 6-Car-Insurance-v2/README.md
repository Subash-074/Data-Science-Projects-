# Car Insurance Analysis - Version 2

## Overview
This project provides an alternative analysis of car insurance data with different approaches, deeper exploration, and enhanced visualizations.

## Dataset
- **File**: `car_insurance.csv`
- **Content**: Car insurance data with customer details, vehicle information, and claim records

## Project Goals
- Advanced analysis of insurance claim patterns
- Feature importance for risk prediction
- Comparative analysis with version 1
- Enhanced visualization and insights
- Model optimization and evaluation

## Files
- `notebook.ipynb` - Detailed analysis notebook
- `car_insurance.csv` - Insurance dataset
- `car.jpg` - Reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Advanced statistical analysis

## Key Insights
- Refined risk assessment models
- Feature interactions and correlations
- Enhanced prediction accuracy
- Business recommendations for insurance pricing
