# Car Insurance Analysis - Version 1

## Overview
This project analyzes car insurance dataset to understand factors affecting insurance claims, premiums, and risk assessment.

## Dataset
- **File**: `car_insurance.csv`
- **Content**: Car insurance data with customer details, vehicle information, and claim records

## Project Goals
- Analyze factors influencing insurance claims
- Identify high-risk customer profiles
- Explore premium pricing factors
- Study claim frequency and severity
- Develop predictive models for risk assessment

## Files
- `notebook.ipynb` - Main analysis notebook
- `car_insurance.csv` - Insurance dataset
- `car.jpg` - Reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (for modeling)

## Key Insights
- Demographics impact on claim frequency
- Vehicle characteristics affecting insurance risk
- Premium determinants
- Predictive factors for claims
