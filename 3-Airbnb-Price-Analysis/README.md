# Airbnb Price Analysis

## Overview
This project analyzes NYC Airbnb listing prices to understand pricing factors, market trends, and geographic price variations.

## Dataset
- **Files**: 
  - `data/airbnb_price.csv` - Listing prices and features
  - `data/airbnb_last_review.tsv` - Review and rating data
  - `data/airbnb_room_type.xlsx` - Room type information

## Project Goals
- Analyze factors influencing Airbnb pricing
- Identify price differences by neighborhood and room type
- Study seasonal pricing patterns
- Predict prices based on listing features
- Analyze customer reviews and ratings

## Files
- `notebook.ipynb` - Main analysis notebook
- `data/` - Datasets in multiple formats
- `nyc.jpg` - NYC reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (for modeling)

## Key Insights
- Price determinants and correlation analysis
- Geographic price variations across NYC neighborhoods
- Room type impact on pricing
- Review ratings distribution and influence on prices
