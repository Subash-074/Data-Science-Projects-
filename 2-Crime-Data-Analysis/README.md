# Crime Data Analysis

## Overview
This project analyzes Los Angeles crime data to identify patterns, trends, and insights about criminal activity in the city.

## Dataset
- **File**: `crimes.csv`
- **Content**: LA crime incidents with dates, locations, types, and details

## Project Goals
- Analyze crime distribution across neighborhoods
- Identify crime trends over time
- Explore seasonal patterns in criminal activity
- Determine high-risk areas and times
- Visualize crime hotspots

## Files
- `notebook.ipynb` - Main analysis notebook
- `crimes.csv` - Crime dataset
- `la_skyline.jpg` - Reference image

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Geospatial analysis tools

## Key Concepts
- **Geospatial Analysis** - Mapping and location-based insights
- **Temporal Analysis** - Time-series and seasonal patterns
- **Hotspot Detection** - Identifying high-crime areas
- **Exploratory Data Analysis** - Data exploration and profiling
- **Pattern Recognition** - Identifying recurring patterns
- **Data Visualization** - Geographic and temporal visualizations

## Key Insights
- Geographic distribution of crime in LA
- Temporal patterns and seasonal trends
- Crime type frequency and severity analysis
